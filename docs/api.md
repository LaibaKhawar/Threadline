# API

Interactive docs: `http://localhost:8000/docs` (OpenAPI generated by FastAPI). All endpoints except
`/api/auth/*`, `/api/health` and `/api/system/status` require a session cookie; unsafe methods require
`x-csrf-token`. Everything is scoped to the signed-in user.

| Area | Endpoints |
|---|---|
| Auth | `POST /api/auth/register · login · logout · demo`, `GET /api/auth/me` |
| Overview | `GET /api/dashboard`, `GET /api/briefing`, `GET/PUT /api/briefing/config`, `GET /api/search?q&mode&types`, `GET /api/timeline` |
| Assistant | `POST /api/assistant/ask`, `GET /api/assistant/tools`, `GET /api/conversations[/{id}]`, `GET /api/runs/{id}`, `POST /api/runs/{id}/feedback`, `GET /api/proposals`, `POST /api/proposals/{id}` |
| Content | `GET /api/threads[/{id}]`, `GET /api/emails/{id}`, `GET /api/events[/{id}]`, `GET /api/events/{id}/brief`, documents `GET/POST/DELETE /api/documents`, `/api/documents/{id}/download`, notes CRUD |
| Work | tasks CRUD, `PUT /api/tasks/settings/auto-create`, projects CRUD + detail, commitments list/detail/`PATCH` (corrections)/candidates, decisions list/`PATCH`, `GET/POST /api/inferences` |
| People & graph | `GET/PATCH /api/people/{id}`, `POST /api/people/merge`, `/split`, merge-candidates; `GET /api/graph/overview · search · node/{type}/{id}?as_of`, `POST /api/graph/edges/{id}/reject` |
| Proactive | `GET /api/insights`, `POST /api/insights/{id}` (feedback), notifications + preferences |
| System | integrations (catalog, create, sync, privacy flags, disconnect, delete data, Google OAuth), jobs, privacy (mode, inventory, export, clear), settings, models health, onboarding, memory rebuild, activity, costs, evaluation |
